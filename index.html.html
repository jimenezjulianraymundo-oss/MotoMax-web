Baja Cilindrada

125cc - 250cc. Perfectas para principiantes y uso urbano. Económicas y fáciles de manejar.

  • ✓ Bajo consumo de combustible
  • ✓ Fácil mantenimiento
  • ✓ Ideales para ciudad
  • ✓ Precio accesible

Media Cilindrada

300cc - 650cc. Balance perfecto entre potencia y control. Para conductores intermedios.

  • ✓ Versatilidad ciudad/carretera
  • ✓ Buena relación potencia/peso
  • ✓ Confort en viajes largos
  • ✓ Tecnología avanzada
🏁

Alta Cilindrada

700cc+. Máxima potencia y prestaciones. Para conductores experimentados que buscan adrenalina.

  • ✓ Máxima potencia
  • ✓ Tecnología de punta
  • ✓ Prestaciones deportivas
  • ✓ Diseño agresivo
